# JackpotCheck - Match Possibility Analyzer  

**A powerful tool for analyzing all possible outcomes of 12-match predictions.**  

## Features  
- Generate all possible match outcome combinations (H=Home, A=Away, D=Draw)  
- Customize match names for easy identification  
- Filter results by specific outcomes or patterns  
- Star and save favorite combinations  
- Detailed view for each possibility  
- Persistent storage using localStorage  

## Tech Stack  
- Pure HTML/CSS/JavaScript  
- Bootstrap 5 for responsive design  
- Bootstrap Icons for clean UI elements  

## How It Works  
1. Name your matches for better identification  
2. Apply filters to narrow down results  
3. Star interesting combinations for quick access  
4. Click any possibility to see detailed breakdown  

The app efficiently handles all 531,441 possible combinations while providing a clean, user-friendly interface.
